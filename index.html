Portage

Build a flow once, ship it anywhere

You build the logic visually in Postman Flows, or just describe it to an LLM, and Portage turns it into a live, running app on whatever backend fits, no plumbing required. Think of it as a forwarding desk for flows: it reads what you built, works out what it needs, generates the files each backend wants, and ships it. Flows builds the logic, Astro runs the agent, and the flow itself never changes, so you can let Portage pick the best destination or point it somewhere new yourself.

Recruiter Agent

Recruiting copilot, chat in, ranked shortlist out

An agent that ranks a role's applicants or sources across an entire candidate database. It embeds every candidate into a persistent Qdrant index, retrieves the top matches by similarity, then deep scores them with an LLM using scoring weights that adapt per job description. Email and scheduling happen in the same window.

Serial LVAD Study

Cerebral blood flow analysis for heart pump patients

A clinical web app that analyzes cerebral blood flow physiology in LVAD patients. From raw signals sampled at 125 Hz it computes autoregulation (CA and Mx), cerebrovascular reactivity (CVR), and per beat pulsatility, separating heart driven from pump driven beats. A full Python and Flask port of a MATLAB research tool, with Excel and JSON export.
